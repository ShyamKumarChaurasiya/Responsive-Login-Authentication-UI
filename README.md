# 🔐 Responsive Login & Authentication UI

A modern and responsive authentication interface built using **HTML5, CSS3, and Bootstrap 5**. This project provides a collection of authentication pages with a clean design, responsive layouts, and social login options.

🔗 **GitHub Repository:** https://github.com/ShyamKumarChaurasiya/Responsive-Login-Authentication-UI

---

## 📌 About the Project

The Responsive Login & Authentication UI is a frontend web development project designed to create a user-friendly authentication experience.

The project includes separate pages for login, signup, forgot password, OTP verification, and password reset. It uses Bootstrap's responsive grid system and custom CSS styling to create a consistent interface across different screen sizes.

The main objective of this project was to improve my understanding of responsive web design, Bootstrap components, form layouts, and frontend UI development.

## ✨ Features

- 🔐 Login page with email and password fields
- 📝 Signup page for account creation
- 🔑 Forgot password interface
- 📩 OTP verification page
- 🔄 Set new password interface
- 🌐 Social login UI for Google, Facebook, and LinkedIn
- 📱 Responsive layouts using Bootstrap 5
- 🎨 Custom CSS styling
- 🖼️ Custom logo, background, and social media icons
- 🔗 Navigation between authentication pages

## 🛠️ Technologies Used

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/ShyamKumarChaurasiya/Responsive-Login-Authentication-UI.git
```

### 2. Navigate to the Project Folder

```bash
cd Responsive-Login-Authentication-UI
```

### 3. Run the Project

Open `login_index.html` in your preferred web browser.

You can also use the **Live Server** extension in Visual Studio Code to run the project locally.

No additional installation is required.

## ⚠️ Project Disclaimer

This project is a **frontend authentication UI for educational and portfolio purposes**.

The authentication pages and social login buttons are interface elements. Actual user authentication, OTP verification, password recovery, and social login require backend services or authentication APIs.

Do not use this frontend interface alone to handle real user credentials.
